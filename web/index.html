◎ Project Overview

Explore video as a spatial scene. CHIMERA combines RGB-D reconstruction, object detection, persistent tracking and interactive visualization in a local workbench.

★ Workspace capabilities

  • Calibrated RGB-D point cloud + surface mesh
  • Optional YOLO detection with persistent IDs
  • Orbit, zoom, spatial map and track histories
  • Local sessions, events and downloadable data
  • Webcam, uploaded video and RGB-D snapshots

The demo is synthetic. A single RGB camera cannot supply measured depth or a complete room scan.

Processing settings

Models are optional. Enable only local, trusted checkpoints.

Empty model paths disable inference. CPU model loading may take a minute. Relative depth is not metric distance.

Choose input source

Switching source starts a new recorded session.

RGB-D NPZ keys: rgb (uint8 H×W×3), depth (H×W metres), intrinsics ([fx,fy,cx,cy]). See samples/ in the project.

Start exploring

  1. The synthetic room starts automatically. Drag the scene to orbit; use the mouse wheel to zoom.
  2. Choose Point Cloud, Mesh or Wireframe. Auto Scan rotates the view; Pause stops frame processing.
  3. Use + Source to open a webcam, upload video or load samples/room.npz.
  4. For real detection install requirements-ai.txt and download the models using scripts/download_models.py, then set their paths in Settings.
  5. Export the current cloud/mesh as PLY, session tracks as CSV, or state as JSON.

Coordinates are camera-relative, not a globally registered SLAM map. Monocular estimates use relative units. Refer to README.md for setup, model licenses and limits.
